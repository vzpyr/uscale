# uscale

Minimal web AI image upscaler 

## Features

- Local inference using multithreaded WASM (SIMD) or WebGPU
- Upscayl model ecosystem (`digital-art`, `high-fidelity`, `remacri`, `ultramix-balanced`, `ultrasharp`, `upscayl-lite`, `upscayl-standard`)
- Selectable scale multipliers (`2x`, `3x`, `4x`)
- Interactive split comparison slider
- Batch queue processing/downloading
- Model caching via CacheStorage API
- Zero telemetry, server uploads, or image retention
